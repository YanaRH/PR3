# Курсовая работа: мониторинг самолётов в воздушном пространстве

Проект реализует сбор данных о самолётах в реальном времени с API OpenSky Network, геоданных по странам через Nominatim и сохранение их в PostgreSQL. Данные анализируются через методы класса `DBManager`.

## Цель проекта
Закрепить навыки работы с внешними API, проектированием БД, SQL-запросами (в т.ч. JOIN, агрегации, фильтрация), объектно-ориентированным подходом и соблюдением принципов SOLID.

## Функционал
- Получение координат и границ стран через API Nominatim.
- Получение списка самолётов в воздушном пространстве выбранных стран через API OpenSky.
- Сохранение данных в PostgreSQL (таблицы `countries`, `aircrafts`).
- Аналитические методы через класс `DBManager`:
  - `get_countries_and_aeroplanes_count()` — список стран и количество самолётов в их воздушном пространстве.
  - `get_all_aeroplanes()` — полный список воздушных судов.
  - `get_avg_speed()` — средняя скорость всех самолётов.
  - `get_aeroplanes_with_higher_speed()` — самолёты со скоростью выше средней.
  - `get_aeroplanes_with_keyword(keyword)` — поиск самолётов по подстроке в позывном.

## Стек технологий
- Язык: Python
- API: OpenSky Network, Nominatim (OpenStreetMap)
- БД: PostgreSQL
- Работа с БД: `psycopg2`
- HTTP-запросы: `requests`
- Формат данных: JSON
